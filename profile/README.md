# Właściwości

Baza suplementów diety. Każda opisana właściwość ma badanie naukowe z podanym źródłem.

## Otwarte dane

Ceny suplementów w Polsce na gram składnika, indeks cen sklepów i zawartość pierwiastka w formach chemicznych. Licencja CC BY 4.0.

- [wlasciwosci-dane](https://github.com/wlasciwosci/wlasciwosci-dane): pliki CSV, opis kolumn i plik CITATION.cff do cytowania
- [wlasciwosci.com/dane](https://wlasciwosci.com/dane): najnowsze pliki
